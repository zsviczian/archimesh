# Test And Verify

Map observable acceptance cases to the narrowest reliable tier. Use isolated real PostgreSQL for SQL behavior and a browser for workflows. Cover denial, rollback and stale writes when relevant. Report command, environment, result and any missing evidence.

Use the repository's [engineering workflow](../../../docs/development/workflow.md).

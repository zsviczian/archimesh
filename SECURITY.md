# Security policy

ArchiMesh is under active development for local use with synthetic data. Keep development services on loopback and keep credentials, logs with sensitive content, and database files out of version control.

## Reporting a vulnerability

Use **Report a vulnerability** on the [repository's Security Advisories page](https://github.com/zsviczian/archimesh/security/advisories) when GitHub offers that option. If it is unavailable, use an existing private channel to a maintainer, or open an issue asking how to contact a maintainer privately and omit the vulnerability details.

Include the affected commit, the potential impact, and enough information to understand the report. Redact any credentials or sensitive data and, where relevant, describe observations from a local test with synthetic data. Coordinate public disclosure with the maintainers.

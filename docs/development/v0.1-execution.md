## Decisions and assumptions

- [ADR 0002](../adr/0002-canonical-knowledge-and-scope.md) records the immutable
  Markdown model, optimistic concurrency, transaction-local identity and
  the reference invariants for scopes and views.
- The catalog shows latest recorded knowledge by default. Effective date
  selection and draft proposal overlays are separate operations.
- Only the three configured identities can use the local demo API. Production
  mode disables it. Use project-scoped synthetic data in every lane.
- Browser graph layout updates write the view revision. Membership can be
  authored via the view Markdown. Advanced diagram assembly is deferred.
